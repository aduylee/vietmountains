# VietMountains

A modern web project for exploring mountains, mountain regions, and trekking routes across Vietnam.

## 🚀 Features

- Explore featured mountains in Vietnam
- Search mountains by name
- Explore mountain regions
- Responsive design
- Smooth animations and interactions
- Modern dark UI
- Interactive mountain cards
- Mountain information by region

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## ▶️ Run Locally

Install dependencies:

    npm install

Start the development server:

    npm run dev

Then open:

    http://localhost:5173

## 🔎 Search

VietMountains includes a search feature that allows users to search for mountains by name.

Example:

    Fansipan
    Pu Ta Leng
    Tà Xùa

## 🏔️ Featured Mountains

The project currently includes mountain data such as:

- Fansipan
- Pu Ta Leng
- Tà Chì Nhù
- Tà Xùa
- Lảo Thẩn
- Tả Liên Sơn

## 🗺️ Mountain Regions

VietMountains is designed to explore mountain areas across Vietnam, including:

- Tây Bắc
- Đông Bắc
- Miền Trung
- Tây Nguyên
- Miền Nam
- Miền Tây
